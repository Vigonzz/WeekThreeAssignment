This README covers two Assignments: WeeThreeGolf.java and WeekThreeInfiniteMirror

The main purpose of these programs is to peruse through the book, Pride and Prejudice provided
through GitHub specifically from Proffesor: Cristina Videira Lopes. From
scanning the book, this program provided the top 25 most used words while implementing
the term frequency program. The program WeekThreeGolf follows the: Code Golf style,
which tries to complete thios task in as few lines as possible. The second program: Infinte Mirror,
uses a singifigant part of the program modeling induction. The base case n0 and then the n + 1 rule.

To Run the Program:
 1. Ensure you have Java version 11 or later and
 correctly pathed in your computer's environment.

 2. Have the files stop_words.txt and pride-and-prejudice.txt specifically in the WeekThreeAssignment folder. It
 should be one level above the source folder. Without these files in the correct location the program cannot
 run correctly.

 3. Open your terminal and change directories: cd path/to/WeekThreeAssignment/src
 to enter the program's source folder. You should be able to now identify the file (with the style)
 you would like to open.

Then enter the following:

For WeekThreeGolf.java  (Code Golf):
java WeekThreeGolf.java ../pride-and-prejudice.txt

For WeekThreeInfiniteMirror.java (Infinite Mirror):
java -Xss64m  WeekThreeInfiniteMirror.java ../pride-and-prejudice.txt
